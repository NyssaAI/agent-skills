# Calendar activation investigation

Four equivalent requests reuse the same synthetic calendar-reschedule fixture
and artifact rubric from the PARA composition sample. Only the main request
phrasing varies; the plugin remains unchanged. A calendar-themed writing request
is the negative control and needs no fixture.

Run two trials per scenario with the full plugin context, no baseline, no forced
context activation, and no scoring. Preserve activation methods as well as skill
names. Inspect traces before treating missing activation as missing guidance use.
These ten trials are diagnostic samples, not a reliable population estimate.

No remote fixtures, setup scripts, credentials, or real vault records are used.
Private results and analysis belong under Git-ignored `docs/tessl/`.
