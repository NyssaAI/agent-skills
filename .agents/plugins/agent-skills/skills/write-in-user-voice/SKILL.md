# Write in User Voice

Produce the requested text using applicable, supported voice guidance.

1. Identify the audience, purpose, supplied facts, and required format from the task. Apply personal voice to material written on the user's behalf; preserve attribution and wording where quoted material, native records, third-party text, or destination requirements constrain the task.
2. Resolve the project-local profile using [shared storage](../maintain-writing-voice/references/storage.md). Read applicable `VOICE.md`, optional `STYLE.md`, and relevant approved examples; interpret them with the [profile schema](../maintain-writing-voice/references/profile-schema.md). Do not borrow another project's profile or create a profile during drafting.
3. Follow explicit task directions and required destination standards, then the appropriate context mode and approved preferences. Draft without changing facts, commitments, intent, or uncertainty. Use [drafting and review](references/drafting-and-review.md) to compare style and meaning separately.
4. Present useful finished text in the requested form. If no profile exists, briefly state that limitation and offer [voice setup](../maintain-writing-voice/SKILL.md) while still completing the draft from available task instructions and supplied examples. Do not claim an evidence-backed voice match when evidence is absent or sparse.

Ordinary drafting reads profile files and leaves their bytes unchanged. Route explicit requests to learn or save preferences to [maintain-writing-voice](../maintain-writing-voice/SKILL.md); acceptance of this draft alone does not authorize profile updates, example retention, or sending/publishing the text.
